An interactive, high-performance portfolio showcasing low-latency systems, quantitative engineering projects, distributed backend infrastructure, and network tools.

---

## 🌟 Key Highlights & Features

- **Interactive System Architecture Showcases:** Deep-dive walkthroughs into high-throughput matching engines (LiquidityLens & TradeForge), distributed tech stack reconnaissance engines (StackLens), zero-trust AST security scanners (DontTrust), and stream backpressure proxies (Specter Proxy).
- **Interactive Terminal & Command Palette (`Cmd+K`):** Fast keyboard-driven navigation across sections, project deep-dives, resume downloads, and live contact triggers.
- **Custom Cyberpunk & Minimalist Engineering UI:** Designed with custom typography, glassmorphism cards, glowing state transitions, and responsive data visualizations.
- **Optimized Asset Pipeline:** High-resolution interactive media captures with lazy-loaded responsive galleries and micro-animations.

---

## 🛠 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + Custom CSS Variables & Animations
- **Icons & UI:** Lucide React, Framer Motion
- **Routing & Navigation:** React Router DOM + Custom Modal Overlays
- **Deployment:** Vercel Edge Network

---

## 📁 Project Structure

```text
port/
├── src/
│   ├── assets/              # Architecture diagrams, screenshots & icons
│   ├── components/          # Reusable components (Navbar, CommandPalette, Showcase, Terminal)
│   ├── data/                # Project metadata, metrics, and engineering specifications
│   ├── pages/               # Dedicated deep-dive pages (TradeForge, LiquidityLens, StackLens, etc.)
│   ├── sections/            # Hero, About, Projects, Experience, Skills, Contact
│   ├── styles/              # Global animations, themes, and typography
│   ├── App.jsx              # Application root with router configuration
│   └── main.jsx             # Entry point
├── index.html
├── package.json
└── vite.config.js
```
