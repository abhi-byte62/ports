# Abhishek M R — Portfolio

Personal developer portfolio and interactive showcase for systems engineering, quantitative finance simulations, distributed backends, and security tooling.

**Live:** [abhishekmr.vercel.app](https://abhishekmr.vercel.app)

---

## What's Inside

- **Interactive Architecture Deep-Dives:** Breakdown and walkthroughs for [TradeForge](https://github.com/abhi-byte62/tradeforge), [LiquidityLens](https://github.com/abhi-byte62/liquiditylens), [StackLens](https://github.com/abhi-byte62/stacklens), [DontTrust](https://github.com/abhi-byte62/dontTrust), [Specter Proxy](https://github.com/abhi-byte62/specter-proxy), and [TaskFlow](https://github.com/abhi-byte62/taskflow).
- **Interactive Terminal & Quick Nav (`Cmd+K` / `Ctrl+K`):** Fast keyboard-driven command palette across all sections and deep-dives.
- **Custom Design System:** Minimal dark aesthetic built with Tailwind CSS, custom CSS variables, and lightweight micro-interactions.

---

## Tech Stack

- **Core:** React 19, Vite, Tailwind CSS
- **Libraries:** Framer Motion, Lucide Icons, React Router DOM
- **Deployment:** Vercel

---

## Structure

```text
src/
├── assets/          # Diagrams, screenshots, and visual assets
├── components/      # UI components (CommandPalette, Terminal, Navbar, Modals)
├── data/            # Project specifications, metrics, and case study data
├── pages/           # Dedicated project deep-dive pages
├── sections/        # Main landing sections (Hero, About, Projects, Experience, Skills, Contact)
├── styles/          # Design tokens and global CSS
├── App.jsx          # Root component & routing
└── main.jsx         # Application entry point
```

## Local Setup

```bash
git clone https://github.com/abhi-byte62/ports.git
cd ports
npm install
npm run dev
```
